# Klarnet Hocam

Sol (G) klarnet öğrenme uygulaması. Eğitim, nota okuma, mikrofonla ses analizi, alıştırmalar ve ilerleme takibi.

## Uygulama kimliği

- App Store adı: Klarnet Hocam
- iOS Bundle ID: `com.oguzhanozeren.klarnethocam`
- Tasarım: koyu lacivert ve altın, gerçekçi fotoğraflar

## App icon

Onaylanan ikon: koyu lacivert zemin üzerinde altın klarnet ve sol anahtarı motifi.

## Durum

iOS kaynakları ve TestFlight derlemesi hazırlık aşamasında. Gerçek cihaz testleri yapılmadan App Store'a gönderilmemelidir.
